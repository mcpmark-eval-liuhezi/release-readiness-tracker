# Release Readiness Checklist

Before we cut the release, all of the following must be complete. Each item maps to a tracking sub-issue.

- [ ] Audit open dependencies and pin versions (#2)
- [ ] Draft release notes for the upcoming release (#3)
- [ ] Verify CI pipeline runs green (#4)

## Definition of done

- [ ] All dependency versions are pinned to known-good releases
- [ ] Release notes draft is reviewed and shared with the team
- [ ] CI is green on the release branch with no failing required checks
